# memory/ — 全局记忆（记载规范）

```text
性质：   本目录的**唯一写法规范**（三个文件共用）
含义：   全局记忆 = **我有什么 / 我能用什么 / 我踩过什么** —— 跨所有工作共享的事实层
⛔ 不是：知识库（→ domains/）· 工作记忆（→ task_cards/active/）· 运行期探针（→ .aios/）
状态：   由 **Agent 手维护**；R3（收工维护 runtime）**已实现但默认关**（.aios/r3-wake.json = enabled:false）
```

## 一、三个文件各管什么

| 文件 | 回答 | 判入规则（一句话） |
|---|---|---|
| `INVENTORY.md` | 我**有**什么（项目 / 产物 / 文件 / 数据集） | **别的对话会用到** ⇒ 进这里 |
| `ENV.md` | 我**能用**什么（模型 / API / 账号 / 代理 / 权限 / 路径 / 工具版本） | **机器与账号的能力面** ⇒ 进这里 |
| `PITFALLS.md` | 我**踩过**什么 | **会再踩一次** ⇒ 进这里 |
| `TODO.md` | 我**欠**什么（讨论过但没做 / 未决） | **有讨论结论、但还没落地** ⇒ 进这里（必须带具体卡 / 文件 / 行号指针） |

> 🔴 2026-10-31：`PITFALLS.md` 已被 `tools/experience_push.py` **逐条召回**（`collect_pitfall_chunks()` · `kind="pitfall"` · 权重 4.0）。
> 此前它在 `task_cards/memory/` 下、而检索器只扫 `task_cards` 顶层 ⇒ P1–P64 从未进入召回语料（10 场景实测 3 条零命中；接入后目标坑命中 7/10）。

## 二、⛔ 不写什么
1. 本卡一次性产物（临时脚本 / 中间报告）→ 留在卡里，**不登记**；
2. 知识与经验（pattern / 方法）→ 留 `domains/`，**不搬进来**；
3. **密钥值** → 只记「有 / 没有 / 在哪」；
4. 任何**未经核实**的推断 → 必须标「未核实」。

## 三、条目必须带什么（缺一不可）

| 字段 | 说明 |
|---|---|
| 名称 / 标识 | 人能认出来 |
| 一句话简介 | 它是什么 |
| **位置 / 指针** | 文件路径 / 仓库 / URL（⛔ 不复制内容） |
| 工作记忆在哪 | 对应 `task_cards/active/<项目>/` |
| **状态** | 进行中 / 已上线 / 暂停 / 已废弃 |
| **来源** | 哪张卡 / 哪次探测产生的 |
| **时间** | `YYYY-MM-DD`（**过期就标过期**，⛔ 不静默沿用） |
| 可信度（ENV/PITFALLS 需要） | 探测方式（命令 / 观察 / 推断） |

## 四、谁、什么时候写

| 时点 | 谁 | 写什么 |
|---|---|---|
| 造出新东西 | **造它的人（Agent）** | `INVENTORY` 加一行 |
| 踩到坑 | 踩到的人（Agent） | `PITFALLS` 加一行（现象 / 触发条件 / 处置） |
| 环境变化 | R3 收工维护（当前手做） | `ENV` 刷新状态 + 时间 |
| **讨论出未决项** | 讨论的 Agent | **`TODO` 加一行**（讨论结论 / 现状 / 具体指针）——⛔ 等会话末尾凭记忆补 |
| **卡被释放后** | **R3（唯一写者）** | 维护清单：查漏 · 刷新 · 对账 |

**强制查漏**：R3 的维护清单必须逐条问 ——
`INVENTORY 有新东西没登记吗？· ENV 有变化吗？· PITFALLS 有新坑吗？· 卡状态对吗？· 探针多大？· tests 绿吗？`

## 五、过期与冲突

- 每条带时间；**超过 30 天未复核**的模型/账号条目视为“可能过期”，下次维护优先刷新；
- 同一事实两处不一致 ⇒ **以本目录为准**（用户目录 / 卡里的副本只作引用）；
- 状态变化时**改状态 + 时间**，⛔ 不删除历史行（保留对照）。

## 六、写法示例

```text
INVENTORY：   | AI 顾问 | 产品原型→重构 | 工作记忆 task_cards/active/demo-project/ | 进行中 | 来源 TASK-20261017-001 | 2026-10-27 |
ENV：         | 本地模型 | local | 127.0.0.1:11434 | ⛔ 不存在 | 无进程/端口/接口无响应 | 2026-10-27 | — |
PITFALLS：    | 卡 ID 跨项目重名 | 裸 ID 调 claim/release | 用「项目/ID」定位 | 2026-10-27 实测 exit 1 |
```
