## 三、想自己造一个可核的读数（推荐做法）

```bash
# 1) 先确认包本身是好的
python tools/probes/_clone_selftest.py

# 2) 引一条能力，照它的做法干一件小事，然后对比「有没有它」的差别
python tools/task_card.py create "<你的任务>" --project=示例
python tools/task_card.py claim 示例/<TASK-ID>
python tools/task_card.py capability 示例/<TASK-ID> --name <域能力> --why "<≥8字理由>"
# 3) 收工时把「用了哪几条做法、哪条是本来不会做的」写进卡的 Outcome
```

**判据**：如果你**撤掉某条能力做法后，交付质量没有明显变差**，那这条能力对你就是噪音 —— 按 Q5（移除后是否明显退化）自行裁剪。这是这套东西最希望被外部检验的地方。
