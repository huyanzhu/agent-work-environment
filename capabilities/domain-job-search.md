# 求职·职业 能力（域能力）

> 一个领域一个文件；片不含阶段字段（领域才是分类轴）。

## 什么时候用

当求职 / 评审作品集 / 准备面试时 ⇒ 先对齐目标岗位，建 STAR 事实库，把同一批事实按目标投影成简历与评审证据，只给 3 条最高影响改进，最后演练表达。

## 做法

1. **对齐目标** —— 先问目标岗位级别与栈，再要 2–3 个自选项目；后续所有取舍以此为准
2. **建事实库** —— 先按 STAR 建经历库，把项目写成可复用的事实单元（故事）
3. **按目标投影** —— 把同一批事实投影成不同产物：简历条目（按 JD 挑）或四支柱证据（README / 代码 / 提交史 / 运行证据）
4. **只给 3 条改进** —— 不打分、不罗列缺陷，每个项目只给 3 条最高影响的改进
5. **演练表达** —— 把材料在压力下讲出来：自我介绍 / 项目 / 行为面 / 反问四段演练，讲技术选择与困难解法，把项目框成解决真实问题

## 边界

- ⛔ 不编造经历 / 不替用户改事实：事实库只收用户确认为真的事。
- ⛔ 不打分、不做排名式评审：只给最高影响的 3 条改进。
- ⛔ 不把同一批事实改写成互相冲突的版本：简历条目与评审证据必须同源可对照。
